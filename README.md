## 🔧 Selected projects

| Project | What it is | Stack |
|---|---|---|
| **[GNSS Integrity](https://github.com/X3I-Inc/gnss-integrity)** | Open-source toolkit that flags GPS spoofing/jamming with an Isolation Forest trained only on clean data, then feeds the flag into a 5-state GPS/IMU Extended Kalman Filter that trusts GPS less when it looks suspicious. Detector tested on real TEXBAT recordings; fusion pipeline tested on synthetic ground-truth trajectories, including the detection-latency trade-off. | Python, scikit-learn, NumPy, SciPy |
| **[Spotify for FH6](https://github.com/X3I-Inc/spotify-for-fh6)** | Windows overlay for Forza Horizon 6 that reads live UDP telemetry (speed, RPM, gear) and runs your Spotify audio through a real-time DSP chain, so music sounds like it plays through the car radio. CarPlay-style panel that never steals game focus; no game modification. | Python, Pedalboard, Spotify Web API (PKCE) |
| **Flow 4D Computer Mouse** | Highly customizable analog-input mouse. Sole inventor on PCT application PCT/AZ2024/000007 (WIPO WO2026/090681). I also wrote C firmware that scales sensor polling rate with movement speed (not part of the patent application). | C, embedded firmware |
| **[VERTA](https://verta.today)** | Solar-powered urban environmental sensing network, Samsung Solve for Tomorrow Benelux finalist. I led hardware and systems and wrote the ESP32 firmware. | ESP32, C (ESP-IDF), TypeScript, Next.js, Firebase |
